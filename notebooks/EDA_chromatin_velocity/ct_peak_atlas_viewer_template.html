Fixed peak atlas: celltype × stage accessibility

One point = one genomic peak across the whole developmental course. The maps below summarize its accessibility across pseudobulks. They are separate from the peak × stage trajectory atlas. No temporal direction or root is imposed.

Measured accessibility through development

Curves show measured CPM for the selected celltype. Low-cell pseudobulks remain visible and flagged. Absent combinations stay missing. These are population pseudobulks, not repeated measurements of the same cells.

Interpretation and provenance

New maps use the same 20,000 training peaks and 5,000 held-out peaks, plus 56 marker extras. The explorer displays a subset. Normalization is raw counts divided by each original full-peak library total ×1,000,000; optional log1p is a natural logarithm. PCA uses global centering without feature z-scoring or whitening. Missing source columns are absent. The ≥20-cell sensitivity removes 14 columns, including all six primordial-germ-cell columns.

Original saved PCA/UMAP coordinates were identical in the celltype and Leiden source objects despite their different count matrices. Both representations partition the same stage-specific cell pools. The matched rebuilt Leiden map separates this aggregation change from preprocessing changes.

Separate map fits have arbitrary coordinates and orientations. UMAP distance is not a calibrated measure of accessibility change. Common colors are computed from all 190 celltype × stage columns for comparability; a condition omitted from the ≥20-cell geometry can still be shown as a flagged color. Stage-average colors use the available celltypes. Nearest genes and original cluster labels are annotations, not validated regulatory assignments.
